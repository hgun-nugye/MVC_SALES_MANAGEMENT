**🛒 Sales Management System (ASP.NET Core MVC)**

**📌 Overview**

This project is a Sales Management System developed as part of the Web Application Development course at Nha Trang University.
It is built using ASP.NET Core MVC and Entity Framework Core, following the Model–View–Controller (MVC) architectural pattern.
The system provides a modern, scalable solution for managing products, customers, orders, and sales operations in a web-based environment.

**🎯 Objectives**
- Apply ASP.NET Core MVC concepts in a real-world project.
- Demonstrate Entity Framework Core for database interaction.
- Provide a practical solution for managing sales activities.
- Enhance skills in web app development and software engineering practices.

**⚙️ Features**
- Authentication & Authorization
- Role-based access (Admin, Customer).
- Product Management
- CRUD operations for products.
- Customer Management
- Maintain customer records and profiles.
- Order & Sales Management
- Create, update, and track orders, invoices, and payments.
- Reporting & Analytics
- Generate sales reports and summaries.
- Built with Razor Pages, Bootstrap.
  .....

**🏗️ Technologies Used**
- ASP.NET Core MVC – Web application framework.
- Entity Framework Core – ORM for database operations.
- SQL Server – Database management system.
- Bootstrap / CSS / JavaScript – Frontend styling and interactivity.
- Visual Studio / Visual Studio Code – Development environment.
